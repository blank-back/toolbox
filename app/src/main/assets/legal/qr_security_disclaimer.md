二维码内容识别与图像生成由本地 ZXing 组件完成。

安全检测功能使用 VirusTotal 提供的服务。用户确认检测后，完整 URL 会发送给 VirusTotal，用于查询已有公开报告；若不存在现成报告，应用将向 VirusTotal 提交该 URL 进行扫描。完整 URL 可能包含路径、查询参数、访问令牌或其他敏感信息，请在提交前自行确认其中不含隐私或机密内容。

VirusTotal 的统计与分类来源于 VirusTotal 及其合作的第三方检测引擎，可能存在误报、漏报、报告滞后或暂时不可用的情况。没有引擎命中不代表链接绝对安全，检测结果仅供参考，不构成安全保证、专业建议或访问建议。

VirusTotal 公共 API 受其服务条款、请求额度及其他使用限制约束。因用户提交 URL、依据检测结果进行访问或采取其他操作而产生的风险，由用户自行判断和承担。
