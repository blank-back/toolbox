## 功能

### 二维码工具

- 使用相机扫码，或从相册选择图片，识别二维码中的链接。
- 输入链接生成二维码，支持预览与保存图片。
- 使用 VirusTotal 检测链接。

### Bilibili 媒体

- 根据 BV、AU 号或相关链接，下载封面、视频或音频。

### 歌曲、播放与歌单

- 搜索歌曲，支持流式播放、后台播放、进度控制、通知栏控制与桌面歌词。
- 支持歌曲下载、播放缓存管理和搜索历史。
- 创建歌单，列表循环与随机连续播放。

### 本地媒体播放器

- 选择并播放本地音频或视频。
- 扫描指定目录下的媒体文件。
- 支持后台与熄屏播放、画中画、倍速、暂停、重播、快进和回退。
- 编辑本地视频或音频并导出。

### 游戏资源工具

- 从文件、游戏目录或已安装应用中选择游戏，并自动识别支持的类型。
- 支持 RPG Maker、Unity、KRKR / 吉里吉里及多种视觉小说资源格式。
- 解析并导出图片、音频、视频、文本、代码相关内容和原始资源。
- 为 RPG Maker MV、MZ 与 VX Ace 游戏调整 BGM、BGS、SE、ME 音量, 关闭部分 RPG Maker 游戏的启动 Logo 或开场动画。
